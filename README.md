# \# Content Review Rubric

# 

# A small Python portfolio demo that checks content-review decisions against a fictional, clearly documented practice rubric.

# 

# \## What it demonstrates

# 

# \- Applying defined decision categories consistently.

# \- Writing concise rationales tied to the example evidence.

# \- Checking CSV columns, unique item IDs, allowed categories, and required rationales.

# 

# \## Run

# 

# Requires Python 3.9 or later. No third-party packages are needed.

# 

# ```bash

# python validate\_reviews.py

# python validate\_reviews.py reviews.csv

# ```

# 

# A supplied CSV must include `item\_id`, `category`, and `rationale` columns. The accepted categories are `allow`, `needs\_review`, and `disallow`.

# 

# \## Project files

# 

# \- `review\_guidelines.md` describes the fictional practice rubric.

# \- `validate\_reviews.py` validates built-in examples or a supplied CSV.

# 

# \## Data and scope

# 

# All built-in examples are synthetic. This independent practice project contains no employer, client, or production data. The illustrative categories are not official guidance and do not replace any employer or platform policy.
